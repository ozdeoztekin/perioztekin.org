Independent research prototype

NeuroCalm

An open-source school-wearable prototype testing whether personal EEG/body-signal patterns, a quiet wrist nudge, and a private trigger journal can help someone notice sensory overwhelm earlier.

The question

Can a wearable cue create a few extra seconds of self-awareness?

Sensory overwhelm often becomes visible to other people only after it has already become difficult to manage. NeuroCalm is built around a narrower, testable question: can a personal baseline, a conservative cue algorithm, and a gentle haptic signal help the wearer notice the shift earlier?

The current version does not claim to diagnose, treat, or prove sensory overload. It logs features, cue decisions, and user-entered context so each session can be reviewed instead of guessed from memory.

Theory

Personal baseline first, universal claims last

There is a real neurophysiological literature on sensory processing differences in autism, including EEG, MEG, and fMRI findings (Marco et al., 2011). But the EEG literature is also heterogeneous: a recent meta-analysis found group-level resting-state differences, including reduced relative alpha and increased gamma on average, while also reporting substantial variation across studies (Neo et al., 2023).

That is why NeuroCalm does not treat one band as a magic overload detector. Newer work links alpha activity with sensory behaviors in autistic adults, but also shows how strongly task and context matter (Murray et al., 2025). The prototype therefore asks a smaller question: did this wearer move far enough away from their own quiet baseline that a soft cue is worth testing?

Current prototype

The working loop

  • Input: synthetic streams now; Muse 2 or Muse S/Athena through BrainFlow for live EEG testing.
  • Features: alpha, theta, beta, motion, and signal quality, stored as summaries rather than raw EEG.
  • Detector: personal baseline, calibrated threshold, smoothing, dwell, hysteresis, refractory period, and optional catch trials.
  • Output: ESP32 wristband with DRV2605L haptic driver; live vibration is opt-in after bench testing.
  • Reflection: local trigger journal plus a new session-review command for signal quality, cue count, contexts, and next-step flags.

The newest prototype improvement is practical: after a run, the system can summarize whether the session had enough usable signal, how many cues fired, whether catch trials were withheld, and what contexts the wearer logged.

Testing path

What has to pass before school wear

  • Run the synthetic loop and confirm the session log contains no raw EEG samples.
  • Bench-test the ESP32 wristband off-body and make sure the vibration is gentle and easy to stop.
  • Run a Muse eyes-open/eyes-closed alpha sanity check at home. If alpha does not move reliably, the project should not pretend it has a useful EEG signal.
  • Calibrate on a quiet personal baseline and set a false-nudge budget before wearing it.
  • Use shadow mode before haptic mode; use school mode only with permission and no caregiver notices at first.
Why it is different

Not a meditation headband, not a crisis alarm

Commercial EEG products already exist. NeuroCalm is different because the workflow is school-specific: a tolerable wrist nudge, local privacy, trigger journaling, consent-based caregiver check-ins, and open-source documentation. Wearable stress research often combines automatic sensing with self-report, which fits this design better than pretending the sensor alone knows the whole story (Gonzalez Ramirez et al., 2023; Hickey et al., 2021).

Limits

The limits belong on the box

NeuroCalm is a prototype, not a medical device. It does not diagnose, treat, prevent, or cure anything. The current claim is feasibility: whether personalized physiology plus a quiet cue and a reviewable journal can support earlier self-awareness. A useful failure is still useful if it shows the signal is too noisy, the cue is intrusive, or the workflow does not help the wearer.
