Why Color Alone Can Hide Your Message

Color Vision & Redundant Cues

Color is built by comparing cone signals, so a key that uses hue alone may lose its meaning for some viewers.

The Science

  • Most people have three cone types in the retina, each responding best to a different range of wavelengths, and the nervous system compares them.
  • For example, if one cone type is absent, there are two channels to compare instead of three, limiting the distinctions the system can make.
  • A map key that uses only two similar colors puts all its meaning into one distinction; if that distinction disappears, the meaning goes with it.

The Protocol

  • Give each category a second cue besides hue: a different shape, a pattern such as a dashed line, or a direct written label.
  • Check each category in turn: can you tell which one it is without its hue? If not, revise that part of the key.
  • Keep each extra cue consistent throughout the graphic, so a dashed line never changes meaning halfway through.

See it in real life

Example

Two courses, one gray line

The food bank’s Thanksgiving fun run has a 5K and a 10K that share the first mile and split at the park gate. Delphine drew the course map on her tablet, with little turkeys at the water stops, and it’s going on the start-line banner and the flyers.

Her printer is out of color ink, so the test copy comes out in gray, and at the park gate the courses run together. She drew the short course in red and the long one in green, and on paper they’re the same gray line, with nothing else to tell them apart.

A gray copy isn’t a test of anyone’s eyes, but it asks whether anything besides hue keeps the courses apart. Most people have three types of cones in the retina, each responding best to a different range of wavelengths, and the nervous system compares their signals. If one type is absent, there are two signals to compare instead of three, which limits the distinctions a viewer can make. A key that runs on hue alone puts all its meaning into one distinction, and if that distinction disappears for someone, so does the route.

Delphine keeps the colors and gives each course a second cue. The long course becomes a dashed line, the short one stays solid, and she writes the distance along each line every half mile. Then she checks each course on a copy with every line in black, asking whether she can still tell which is which. The inset map still shows the long course as solid, so she fixes it, since a dashed line can’t change meaning from one map to the other.

The all-black copy reads clearly from start to finish, and the race director signs off on it. On race morning Delphine watches a man in a turkey hat trace the dashed line on the banner with a finger, then head for the 10K side of the gate.

  1. Where it stallsOn the gray test print, her two race courses become one line.
  2. What changes itShe makes the 10K dashed and labels both courses along the way.
  3. What happens nextWith every line switched to black, the map still reads clearly.

Try it yourself · 5 minutes

The one-pencil test

Get two markers or colored pencils in colors that look clearly different to you, one plain pencil and two sheets of paper, one of them thin enough to trace through.

  1. Draw a small map with two routes that start together and then split, one route in each color, and a key in the corner showing which color means which.
  2. Put the thin sheet on top and trace both routes and the key with the plain pencil. Hand the tracing to someone and ask which route is which.
  3. Back on your map, give one route a second cue, like dashes, dots or a short label written along the line, and add it to the key.
  4. Trace it again with the plain pencil and ask the same question.

What you’ll probably notice. Traced in pencil, the first map can’t be read, because the only difference between the routes was hue, and the pencil took it away. The second one can, since the dashes or the labels carry the meaning by themselves. Color comes from comparing signals from different cone types, and someone with fewer signals to compare may lose a difference you see easily, so the second cue keeps the message for them too. It’s a check on the design, not on anyone’s vision.

Step by step

Give every color a backup

For anything that uses color to mean something, like a map, a chart, a comic or a game board.

  1. List what each color means. Write down every category your colors stand for, like each route, team, character or kind of stop.
  2. Add a second cue to each. Give every category a different shape, a pattern such as a dashed line, or a written label right on it.
  3. Keep the colors too. Color can still be useful, so the second cue goes on top of it rather than replacing it.
  4. Check each one without its hue. Make a copy with every category in the same color, or trace it in pencil, and ask whether you can still tell which one is which. If you can’t, revise that part of the key.
  5. Keep every cue consistent. A dashed line has to mean the same thing on every page and in every inset, so it never changes meaning halfway through.

How to tell it’s working. On the one-color copy, count how many categories you can name correctly, and then ask someone who hasn’t seen the original to try. Aim for all of them, and check again after every change to the key.

When it gets hard. Patterns can look too much alike when they’re small, like fine dashes next to fine dots. Make the difference bold, or write the label on the line so the pattern doesn’t have to do the job alone.

Good to know. This is a design check, not a vision test, and a second cue won’t cover every access need.
