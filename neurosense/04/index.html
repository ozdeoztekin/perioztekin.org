Why ADHD Brains Can't Start (But Can Hyperfocus)

Tonic vs Phasic Dopamine

ADHD brains don't lack attention. They lack steady dopamine. Boring tasks never cross the threshold; engaging ones flood it.

The Science

  • Most brains run on tonic dopamine — a steady drip that makes ordinary tasks 'startable.'
  • Volkow (2009, 2011): ADHD brains run lower tonic and higher phasic. The drip is too weak to start a worksheet. But a video game can flood the system.
  • That's why hyperfocus and 'can't start' coexist in the same brain. Same hardware, different fuel pattern.

The Protocol

  • Five-minute 'dopamine appetizer': do something high-interest first — then pivot to the boring thing.
  • Body double: work with someone else physically present. PFC signal jumps.
  • Novelty reset: change rooms. The salience network re-engages.
